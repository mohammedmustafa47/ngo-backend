# ngo-backend
A food donation system aimed at providing support for poor people, shelters, and displaced people across India.

A **Django REST Framework**–based backend for managing food donations through an NGO network.  
It allows **donors** to post food donations, **volunteers** to pick and deliver them, and **admins** to monitor the entire process.

---

## 🚀 Features

- 👤 **Role-based Access Control** (Admin, Donor, Volunteer)
- 🔐 **JWT Authentication**
- 🍛 Donor can post food donations
- 🚚 Volunteer can pick and deliver donations
- 🧾 Admin can view all donation activities
- ⚙️ Auto-lock system: once a donation is picked, others cannot pick it
- 🖼️ Image upload for donations
- 📡 RESTful APIs (frontend-ready)

---

## 🧩 Tech Stack

- **Backend:** Django 5.x  
- **API:** Django REST Framework  
- **Auth:** JWT (JSON Web Token)  
- **Database:** SQLite (default) /mysql
- **Language:** Python 3.x
